03 / COMPRUEBA
Cómo interpretar las cuatro propiedades

xRy significa “x se relaciona con y”, no necesariamente x=y. Las condiciones se revisan sobre todos los elementos y pares, no solo sobre un ejemplo.

Reflexiva: deben aparecer (a,a), (b,b), (c,c), … para todo el conjunto.

Simétrica: si aparece (a,b), debe aparecer (b,a), y lo mismo para todos los pares.

Asimétrica: si aparece (a,b), no puede aparecer (b,a); tampoco puede haber lazos. No ser simétrica no basta: R={(a,b),(b,a),(b,c)} no es simétrica porque falta (c,b), pero tampoco es asimétrica porque contiene (a,b) y (b,a).

Transitiva: si aparecen (a,b) y (b,c), debe aparecer (a,c). También se revisan cadenas que repiten elementos. Si no hay cadenas de dos enlaces, no existe un contraejemplo y la condición se cumple.
